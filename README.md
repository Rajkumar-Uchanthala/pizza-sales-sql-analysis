# Pizza Sales Analysis Using SQL

## Project Overview
This project analyzes pizza sales data using SQL to identify sales trends, revenue patterns, order information, and popular pizza products.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Dataset Files
- `orders.csv` — Order date and time details
- `order_details.csv` — Pizza quantities and order details
- `pizzas.csv` — Pizza prices and sizes
- `pizza_types.csv` — Pizza names, categories, and ingredients

## SQL Concepts Used
- SELECT and WHERE
- Aggregate functions
- GROUP BY and ORDER BY
- JOIN operations
- Subqueries
- Window functions
- Revenue analysis

## SQL Queries
The `sql_queries.sql` file contains the SQL queries used to answer business questions about pizza sales.

## Objective
To practice SQL and derive useful business insights from pizza sales data.
